# Zblog

Personal technical blog based on [AstroPaper](https://github.com/satnaing/astro-paper), published with GitHub Pages.

- Blog: https://zzkkoo8.github.io/Zblog/
- Wiki: https://zwiki.gitbook.io/zwiki-docs/
- Posts: `src/content/posts/`

## Local development

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Production verification:

```bash
pnpm lint
pnpm format:check
pnpm build
```

AstroPaper upstream baseline: `35cfa7fbe0b897306d27670d3819e55d5205f3dd`.
